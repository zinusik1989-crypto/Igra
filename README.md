# Колесо удачи — нейрофотосессия

Интерактивная мини-игра «Колесо удачи» для промо-лендинга нейрофотосессии.
Весь код в одном файле — **`igra.html`**.

## Как открыть

Дважды кликните **`igra.html`** — игра откроется в браузере.
Ничего устанавливать не нужно (без Node.js, без сборки).

## Возможности

- Колесо из 6 секторов с иконками и подписями
- Плавное вращение с замедлением и определением приза
- Конфетти, свечение, бегущие огоньки, вспышка при выигрыше
- Звуки вращения и выигрыша (кнопка 🔊 для выключения)
- Карточка приза: промокод с копированием, круговой таймер-дедлайн
- Кнопка «Поделиться» (мессенджеры на телефоне / копирование на ПК)
- Адаптив для мобильных и десктопов

## Настройка

Откройте `igra.html` в редакторе:

- **Призы и тексты** — массив `PRIZES` (можно менять названия, описания, цвета, иконки, префиксы промокодов).
- **Время таймера** — переменная `DEADLINE_SEC` (по умолчанию 15 минут).
- **Ссылка для «Поделиться»** — переменная `SHARE_PAGE_URL` (пусто = текущий URL).
- **Действие CTA-кнопки** — обработчик `ctaBtn` (сейчас показывает приз и промокод; подключите свой переход на Telegram / WhatsApp / форму).

## Размещение на сайте

Загрузите `igra.html` на любой хостинг или вставьте содержимое в страницу лендинга.
